# كيف تحوّل BUILD SPEEDRUN إلى موقع إلكتروني

هذا المشروع **موقع ويب جاهز** (Next.js)، وليس فيديو ولا سكربت وهمي.
المتصفح يرسم المبنى ثلاثي الأبعاد مباشرة.

---

## 1) شغّله على جهازك

افتح Terminal داخل مجلد المشروع:

```bash
cd build-speedrun
npm install
npm run dev
```

ثم افتح المتصفح على:

**http://localhost:3000**

- الصفحة الرئيسية `/` = التجربة ثلاثية الأبعاد
- `/projects` = صفحة المشروع
- `/about` = عن التقنية

---

## 2) ابنِ نسخة الإنتاج

```bash
npm run build
npm start
```

هذا يجهّز الموقع للرفع على سيرفر حقيقي.

---

## 3) انشره أونلاين (أسهل طريقة: Vercel)

1. ارفع المجلد على GitHub.
2. ادخل [vercel.com](https://vercel.com) وسجّل بحساب GitHub.
3. New Project → اختر المستودع.
4. Framework يظهر تلقائيًا: **Next.js**.
5. اضغط Deploy.

بعد دقائق تحصل على رابط مثل:

`https://build-speedrun.vercel.app`

يمكنك ربط دومين خاص من إعدادات Vercel → Domains.

بدائل: Netlify أو أي VPS مع `npm run build && npm start`.

---

## 4) ماذا تغيّر ليصبح موقع شركتك؟

| الملف | ماذا يفعل |
|---|---|
| `src/data/buildingConfig.ts` | أبعاد المبنى (لا تغيّرها في أكثر من مكان) |
| `src/app/layout.tsx` | اسم الموقع والوصف |
| `src/components/ui/HUD.tsx` | أزرار الواجهة |
| `src/app/about/page.tsx` | صفحة من نحن |
| `src/app/projects/page.tsx` | صفحة المشاريع |

الاسم الحالي للمبنى: **Aether Residences** — غيّره من `buildingConfig.ts` والـ HUD.

---

## 5) متطلبات الزائر

- متصفح حديث (Chrome / Edge / Safari / Firefox)
- جهاز مكتبي أفضل للأداء (تجربة 3D)
- الجوال يعمل لكن أخف

---

## 6) التحكم في الموقع

- **START BUILD** ثم **PLAY**
- شريط التقدم أو عجلة الماوس = مراحل البناء
- **D** = وضع المطوّر
- مسطرة = تشغيل / إيقاف
